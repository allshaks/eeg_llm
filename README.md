# EEG LLM

[![Practical Work Report PDF](https://img.shields.io/badge/Practical_Work_Report-PDF-blue)](docs/PracticalWork(Bsc)Kamm.pdf) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository explores a transformer-based approach and PCA for uncovering temporal dynamics of SEP EEG data.

## Project Structure

- `models/` – Saved Hugging Face model weights and configuration.
- `notebooks/` – PCA and transformer forecasting notebooks.
